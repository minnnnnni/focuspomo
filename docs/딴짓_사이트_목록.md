# FocusPomo 딴짓 사이트 목록

2026-11-15 · 신명철 (초안, WIN-04) · 팀 확인 필요

> 코드의 기준은 `config/window_rules.py`의 `DISTRACTION_DOMAIN_GROUPS`다. 이 표는 사람이 읽는 사본이다.
> 목록을 바꾸면 이 문서도 같은 PR에서 함께 고친다. `tests/test_window_rules.py`가 두 목록이 같은지 확인한다.

## 어떻게 쓰이나

창 스레드가 1초마다 브라우저 주소창에서 도메인을 읽고(`www.`는 뗌), 이 표에 걸리면 **로컬 규칙상 딴짓**으로 본다 (점수 명세 2.1).

- 10초 슬롯 안에서 딴짓 사이트(또는 [유튜브 영상 분류표](유튜브_영상_분류표.md)에서 딴짓인 영상)가 앞 화면에 **3초 이상**(`DISTRACTION_MIN_SEC`) 있으면 그 슬롯은 `rule_distraction = "foreground"`가 되고, 점수에서 딴짓이다. LLM 결과로 뒤집지 않는다.
- 표의 도메인은 **하위 도메인까지** 걸린다. `instagram.com`이면 `m.instagram.com`, `www.instagram.com`도 딴짓이다.
- 그래서 공부에도 쓰는 큰 포털은 딴짓인 하위 도메인만 적는다. 예: `naver.com` 전체가 아니라 `comic.naver.com`, `chzzk.naver.com`.
- 표에 없는 사이트는 세션이 끝난 뒤 LLM이 작업/딴짓/미분류로 분류한다.
- 판정은 로컬에서만 한다. 주소 전체·창 제목은 저장하거나 내보내지 않는다.

**넣는 기준**: 집중 세션 중에 열려 있으면 거의 항상 공부와 무관한 사이트. 애매하면 넣지 않고 LLM에 맡긴다.

## 일부러 넣지 않은 사이트

딴짓일 때가 많아도 공부·팀 작업에 쓰는 경우가 있어 규칙에서 뺐다. 이 사이트들은 LLM이 분류한다.

| 사이트 | 넣지 않은 이유 |
| --- | --- |
| youtube.com | 강의도 많다. 영상은 [유튜브 영상 분류표](유튜브_영상_분류표.md)로 따로 판정하고 LLM에 보내지 않는다. 홈·검색 화면은 LLM이 미분류로 둔다 |
| reddit.com | 개발 질문 검색 결과로 자주 열린다 |

## 바꾸는 방법

1. `config/window_rules.py`의 `DISTRACTION_DOMAIN_GROUPS`에서 알맞은 그룹에 도메인을 넣거나 뺀다 (소문자, `www.`·`https://` 없이).
2. 이 문서의 표도 같이 고친다.
3. `python -m pytest tests/test_window_rules.py`로 두 목록이 맞는지 확인한다.
4. 실제로 걸리는지 보려면 `python -m window_tracker.tracker --duration 60 --domain`을 켜고 그 사이트를 3초 이상 띄운다. 출력의 `rule_distraction='foreground'`와 슬롯 구성의 `*` 표시를 확인한다.
