# FocusPomo 개발 환경 설정 가이드

> 팀원 전원이 **같은 환경**에서 개발하기 위한 설정 순서입니다. 위에서부터 차례대로 따라 하면 됩니다.
> 기준 환경: **Windows 10/11 · PowerShell · Python 3.12.10 · venv**

---

## 0. 한눈에 보기

| 항목 | 값 |
|---|---|
| OS | Windows (팀 전원 통일) |
| Python | **3.12.10** (패치 버전까지 정확히 일치) |
| 가상환경 | `venv` — 폴더 이름 `.venv` (레포에 올리지 않음) |
| 패키지 목록 | `requirements.txt` (버전 고정) |
| GUI | PySide6 |
| Face Landmarker 모델 | `models/face_landmarker.task` (레포에 포함되어 있음, 따로 다운로드 불필요) |
| Docker / WSL / AWS | 사용하지 않음 |

전체 순서: **Python 설치 → Git 설치 → 레포 clone → 가상환경 생성 → requirements.txt 설치 → 동작 확인**

---

## 1. Python 3.12.10 설치

### 1-1. 설치 파일 다운로드

1. 아래 페이지에 접속합니다.
   https://www.python.org/downloads/release/python-31210/
2. 페이지 아래쪽 **Files** 표에서 **Windows installer (64-bit)** (`python-3.12.10-amd64.exe`)를 받습니다.

> ⚠️ Microsoft Store 버전이나 다른 3.12.x 버전은 설치하지 마세요. 패치 버전이 다르면 `requirements.txt` 설치 결과가 팀원마다 달라질 수 있습니다.

### 1-2. 설치

1. 설치 파일을 실행합니다.
2. 첫 화면 아래쪽의 다음 두 항목을 **체크**합니다.
   - ✅ **Use admin privileges when installing py.exe**
   - ✅ **Add python.exe to PATH**
3. **Install Now** 를 누릅니다.
4. 마지막 화면에 **Disable path length limit** 버튼이 보이면 눌러 줍니다 (긴 경로 문제 예방).

### 1-3. 설치 확인

PowerShell을 **새로** 열고 입력합니다.

```powershell
python --version
py -3.12 --version
```

두 줄 모두 아래처럼 나와야 합니다.

```
Python 3.12.10
```

> 💡 이미 다른 Python(예: 3.11, 3.13)이 깔려 있어서 `python --version`이 다른 버전을 보여줘도 괜찮습니다. `py -3.12 --version`이 `Python 3.12.10`이면 됩니다. 아래 3단계에서 가상환경을 만들 때 `py -3.12`로 버전을 지정하기 때문입니다.

## 2. Git 설치 및 초기 설정

### 2-1. 설치

이미 설치되어 있다면 건너뜁니다. 확인:

```powershell
git --version
```

명령을 찾을 수 없다고 나오면 https://git-scm.com/download/win 에서 설치합니다 (설치 옵션은 기본값 그대로 두면 됩니다). 설치 후 PowerShell을 다시 열어 `git --version`으로 확인합니다.

### 2-2. 사용자 정보 등록 (최초 1회)

커밋에 표시될 이름과 이메일입니다. **GitHub 계정 이메일**을 사용하세요.

```powershell
git config --global user.name "홍길동"
git config --global user.email "your-email@example.com"
```

### 2-3. 줄바꿈 설정 (권장)

```powershell
git config --global core.autocrlf true
```

## 3. 레포지토리 clone

### 3-1. 작업 폴더로 이동

원하는 위치로 이동합니다. **경로에 한글·공백이 없는 곳**을 권장합니다 (MediaPipe 등 일부 라이브러리가 한글 경로에서 모델 파일을 못 읽는 경우가 있습니다).

```powershell
mkdir C:\dev
cd C:\dev
```

### 3-2. clone

```powershell
git clone https://github.com/<OWNER>/focuspomo.git
cd focuspomo
```

> `<OWNER>` 부분은 레포 주소로 바꿔 주세요. GitHub 레포 페이지에서 초록색 **Code** 버튼 → **HTTPS** 주소를 복사하면 됩니다.
> 처음 clone/push 할 때 GitHub 로그인 창이 뜨면 브라우저로 로그인하면 됩니다.

### 3-3. 모델 파일 확인

clone 후 모델 파일이 제대로 받아졌는지 확인합니다.

```powershell
dir models
```

`face_landmarker.task` 파일이 보이면 정상입니다.

## 4. 가상환경(venv) 생성 및 활성화

### 4-1. 생성 (최초 1회)

레포 폴더(`focuspomo`) 안에서 실행합니다.

```powershell
py -3.12 -m venv .venv
```

`.venv` 폴더가 생깁니다. 이 폴더는 `.gitignore`에 들어 있어 레포에 올라가지 않습니다.

### 4-2. 활성화 (터미널을 열 때마다)

```powershell
.\.venv\Scripts\Activate.ps1
```

성공하면 프롬프트 앞에 `(.venv)`가 붙습니다.

```
(.venv) PS C:\dev\focuspomo>
```

#### ❗ "이 시스템에서 스크립트를 실행할 수 없으므로…" 오류가 뜨는 경우

PowerShell 실행 정책 때문입니다. 아래 명령을 **한 번만** 실행한 뒤 다시 활성화하세요.

```powershell
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
```

(`Y` 입력으로 확인)

### 4-3. 가상환경의 Python 버전 확인

```powershell
python --version
```

`(.venv)`가 붙은 상태에서 `Python 3.12.10`이 나와야 합니다.

### 4-4. 비활성화

```powershell
deactivate
```

## 5. requirements.txt 패키지 설치

`(.venv)`가 활성화된 상태에서 실행합니다.

```powershell
python -m pip install --upgrade pip
pip install -r requirements.txt
```

MediaPipe, OpenCV, PySide6 등 용량이 큰 패키지가 있어 몇 분 걸릴 수 있습니다.

### 설치 확인

```powershell
pip list
```

`requirements.txt`에 적힌 패키지와 버전이 목록에 있는지 확인합니다. 핵심 라이브러리 import 테스트:

```powershell
python -c "import cv2, mediapipe, PySide6, win32gui; print('OK')"
```

`OK`가 출력되면 설치 완료입니다.

## 6. VS Code 설정 (사용하는 경우)

1. VS Code에서 `focuspomo` 폴더를 엽니다.
2. `Ctrl + Shift + P` → **Python: Select Interpreter**
3. `.\.venv\Scripts\python.exe` 를 선택합니다.

이후 VS Code 내장 터미널을 열면 가상환경이 자동으로 활성화됩니다.

## 7. 평소 작업 흐름

### 작업 시작할 때

```powershell
cd C:\dev\focuspomo
.\.venv\Scripts\Activate.ps1
git pull
pip install -r requirements.txt   # 다른 팀원이 패키지를 추가했을 수 있으므로
```

### 새 패키지를 추가해야 할 때

아무 버전이나 설치하고 끝내지 말고, **반드시 `requirements.txt`에 버전을 고정해 반영**한 뒤 커밋해 주세요.

```powershell
pip install 패키지이름
pip show 패키지이름          # 설치된 버전 확인
```

`requirements.txt`에 `패키지이름==버전` 형식으로 한 줄 추가하고, 팀 채널에 "패키지 추가했으니 `pip install -r requirements.txt` 다시 해 주세요"라고 공유합니다.

> ⚠️ `pip freeze > requirements.txt`로 통째로 덮어쓰면 개인 환경에만 있던 패키지까지 섞여 들어갈 수 있으니, 직접 한 줄씩 추가하는 방식을 권장합니다.

## 8. 커밋하면 안 되는 것

`.gitignore`에 이미 들어 있지만, 한 번 더 확인해 주세요.

| 대상 | 이유 |
|---|---|
| `.venv/` | 개인 가상환경 — 각자 `requirements.txt`로 재생성 |
| `data/` | 세션 기록(`sessions.jsonl`, `focus_log/`) — 개인정보 성격 |
| `.env`, `config/local_settings.py` | **LLM API 키** — 절대 레포에 올리지 않기 |

API 키는 각자 로컬의 `.env` 파일에 두고, 키 값을 메신저·레포에 붙여 넣지 않도록 주의해 주세요.

## 9. 자주 겪는 문제

| 증상 | 해결 |
|---|---|
| `python` 명령을 찾을 수 없음 | Python 설치 시 "Add python.exe to PATH"를 체크하지 않은 경우. 재설치하거나 `py -3.12`로 대신 실행 |
| `python`을 입력하면 Microsoft Store가 열림 | 설정 → 앱 → 고급 앱 설정 → **앱 실행 별칭**에서 `python.exe`, `python3.exe` 끄기 |
| `Activate.ps1` 실행 불가 | 4-2의 실행 정책 명령 실행 |
| `pip install` 중 특정 패키지가 "No matching distribution" | 가상환경 Python이 3.12.10이 아닐 가능성. `python --version` 확인 후 `.venv` 삭제하고 `py -3.12 -m venv .venv`로 다시 생성 |
| 웹캠이 안 열림 | Windows 설정 → 개인정보 → **카메라**에서 "데스크톱 앱이 카메라에 액세스하도록 허용" 켜기. Zoom 등 다른 앱이 카메라를 쓰고 있지 않은지 확인 |
| 모델 파일을 못 찾는다는 오류 | 레포 경로에 한글·공백이 있는지 확인 (3-1 참고) |

가상환경이 꼬였을 때는 지우고 다시 만드는 게 가장 빠릅니다.

```powershell
deactivate
Remove-Item -Recurse -Force .venv
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```
