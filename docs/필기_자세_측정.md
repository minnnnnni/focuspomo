# 필기 자세 측정 가이드 (CV-06)

2026-11-26 · 신명철 · 팀원 각자 한 번씩 측정 부탁

## 왜 재나

노트에 필기하려고 고개를 숙이면 웹캠에서는 눈이 작게 보인다. 시선을 따라 윗눈꺼풀이 내려오고, 카메라가 위에서 비스듬히 보게 되기 때문이다. 지금 규칙(눈 비율이 캘리브레이션 기준의 60% 미만인 상태가 4초 이어지면 졸음)으로는 필기가 졸음으로 잡힐 수 있다. 더 많이 숙이면 얼굴 검출 자체가 끊겨 자리비움으로 잡힌다.

그래서 고개 각도로 "숙임" 상태를 따로 두려고 한다 (아래 [판정 흐름 초안](#판정-흐름-초안)). 몇 도부터 숙임으로 볼지, 숙인 자세에서 눈 비율이 얼마나 줄어드는지, 몇 도에서 얼굴을 놓치는지는 사람과 카메라마다 달라서 실제로 재 보고 정한다.

## 무엇을 재나

`cv_module/measure_head_pose.py`가 웹캠 프레임마다 아래 값을 `data/head_pose/head_pose_<시각>.csv`에 적는다. **영상·사진은 저장하지 않는다.**

| 값 | 뜻 |
| --- | --- |
| 눈 비율 (`ear_ratio`) | 캘리브레이션 기준 대비 눈 비율 (평소=1). 지금 규칙상 감김인지(`closed`)도 같이 |
| 고개 각도 (`pitch_rel`) | 캘리브레이션 때보다 몇 도 숙였는지 (+가 숙임) |
| 표정 점수 (`blink`, `look_down`) | MediaPipe가 주는 눈 감음·시선 아래 점수 (0~1). 아래를 보는 것과 감는 것을 구분하는 데 쓸 수 있는지 본다 |
| 얼굴 위치 (`face_cx`, `face_cy`, `face_w`) | 얼굴을 놓치기 직전 어디에 있었는지 (숙임 vs 일어남) |
| 사람 영역 (`person`) | 사람 영역 분리 모델로 본 화면 속 사람 비율. 얼굴이 안 보여도 정수리·어깨가 보이면 남는다 |

## 실행과 첫 확인

```powershell
python -m cv_module.measure_head_pose               # 다른 웹캠이면 --camera 1
```

1. 창이 뜨면 5초 동안 평소처럼 화면을 본다 (캘리브레이션).
2. **각도 방향 확인**: 고개를 숙였을 때 화면 두 번째 줄 `pitch_rel`이 +로 커지면 정상이다. −로 가면 `f` 키 (또는 `--flip-pitch`로 다시 실행).
3. **사람 영역 확인**: 다섯 번째 줄에 `person 0.xx`가 보이면 정상이다.

화면 글씨는 OpenCV가 한글을 못 그려서 영어다.

| 화면 줄 | 뜻 |
| --- | --- |
| `REC 120s \| WRITE (45s)` | 기록 시간, 지금 고른 상황, 그 상황을 한 시간 |
| `pitch_rel +27.3` | 평소보다 몇 도 숙였는지 |
| `ratio 0.55 -> CLOSED` | 눈 비율. 지금 앱 규칙이면 감김인지 |
| `blink`, `lookDown` | 눈 감음 점수, 시선 아래 점수 |
| `person` | 화면에서 사람 영역 비율 |

## 촬영 순서 (10분 정도)

평소 공부하는 그대로 한다 (카메라 위치, 노트 위치, 조명, 안경). 상황을 시작할 때 숫자 키를 누르고, 다음 상황으로 넘어가는 동안에는 `0`(라벨 없음)을 누른다. 다 하면 `q`.

| 키 | 상황 | 이렇게 | 시간 |
| --- | --- | --- | --- |
| `1` | 화면 보기 | 평소처럼 읽고 타이핑 | 1분 |
| `2` | 필기 | 실제로 노트에 쓰기. 중간중간 화면을 봤다가 다시 쓰기 | 2~3분 |
| `3` | 졸다가 고개 떨굼 | 화면을 보다가 눈을 천천히 감고, 2~3초 뒤 고개를 떨어뜨리고, 5초 뒤 들기. 5번 | 1분 |
| `4` | 숙인 채 졸기 | 필기 자세에서 눈을 감고 10초, 다시 쓰기. 3번 | 1분 |
| `5` | 숙인 채 일어나 나감 | 필기하다 고개를 숙인 채 일어나 카메라 밖으로, 15초 뒤 돌아와 앉기. 2번 | 1분 |
| `6` | 평소 자세에서 나감 | 화면을 보다 일어나 나가고, 15초 뒤 돌아오기. 2번 | 1분 |

- 졸음 흉내(3, 4)는 실제 졸 때처럼 천천히 한다. "졸 때는 눈이 먼저 감기고 고개가 떨어진다"를 확인하는 데이터다.
- 필기(2)는 가장 길게, 자연스럽게 한다. 숙인 각도별 기준값을 여기서 뽑는다.
- 키 `c`는 캘리브레이션 다시, `l`은 눈 랜드마크 표시 켜고 끄기.

## 결과 공유

`q`를 누르면 터미널에 요약이 나오고 `data/head_pose/`에 세 파일이 생긴다: `head_pose_<시각>.csv`(프레임별 숫자), `.json`(기준값), `_summary.txt`(요약). `data/`는 커밋되지 않으므로 **세 파일을 단톡에 올린다** (신명철이 모아서 기준을 정함). 요약은 `python -m cv_module.analyze_head_pose data/head_pose/head_pose_<시각>.csv`로 다시 만들 수 있다.

요약에서 보는 것:

| 요약 항목 | 정할 것 |
| --- | --- |
| 1. 상황별 요약 | 지금 규칙이 필기를 몇 초나 졸음·자리비움으로 잡는지 (문제 크기) |
| 2. 각도 구간별 눈 비율 | 몇 도부터 숙임으로 볼지, 각도 구간별 기준값 |
| 3. 숙이기 직전·직후 눈 비율 | 필기와 졸음을 "숙이기 전 눈 상태"로 구분할 수 있는지 |
| 4. 얼굴을 놓친 구간 | 몇 도에서 얼굴을 놓치는지, 숙임과 자리 이탈을 사람 영역으로 구분할 수 있는지 |

## 판정 규칙 (적용, CV-06)

2026-11-26 측정(노트북 내장 카메라, 안경 없음, 1명)에서 나온 것:

- 필기하려고 숙이면 평소보다 **23~29°에서 얼굴 인식이 끊긴다**. 그 전까지 눈 비율은 0.93~0.99로 거의 그대로라 졸음으로 잡히지는 않았다. 문제는 끊긴 뒤 **자리비움**으로 잡히는 것 (필기 101초 중 56초).
- 졸다 떨굴 때는 끊기기 3~1초 전 눈 비율이 0.22~0.33, 필기는 0.75 이상.
- 얼굴을 놓친 동안 사람 영역: 필기 0.26~0.36 / 깊게 숙임·졸다 떨굼 0.01~0.08 / 빈자리 0.06~0.09.
- 일어나면 얼굴이 위로 올라가며 사라진다 (얼굴 높이 0.80 → 0.25). 돌아와 앉을 때 사람 영역이 0.53~0.61까지 커진다 (숙였다 들 때는 최대 0.43).

그래서 세션 중에는 지금처럼 판정하고, **세션이 끝나면 얼굴을 놓친 구간을 어떻게 놓쳤는지로 다시 나눠** 바뀐 슬롯을 다시 보낸다 (`cv_module/head_down.py`). 위에서부터 처음 맞는 것:

| 순서 | 조건 | 판정 |
| --- | --- | --- |
| 1 | 얼굴이 평소 위치보다 화면 높이 0.2 이상 위에서 사라짐 | 자리비움 (일어남) |
| 2 | 사라지기 3~1초 전, 고개 든 채(15° 미만) 눈 비율 중앙값 < 0.6 | 졸음 (졸다 떨굼). 그 전에 눈 감은 초도 10초까지 졸음 |
| 3 | 다시 잡히기 직전 3초 안에 사람 영역 ≥ 0.5 | 자리비움 (나갔다 돌아와 앉음) |
| 4 | 놓친 동안 사람 영역 중앙값 ≥ 0.15 | 자리에 있음 (머리·어깨가 보임, 필기 등) |
| 5 | 그 밖 | 판정불가 (깊이 숙였는지 나갔는지 구별 불가, 감점 안 함) |

- **얼굴이 보이는 채로 숙인 경우**: 평소보다 10° 이상 숙인 프레임은 눈이 작아도 감김으로 세지 않는다 (`BOWED_EYES_PITCH`). 노트를 내려다보면 눈꺼풀이 내려와 감긴 것처럼 보여서, 살짝 숙여 필기하는 동안 "감김 4초 = 졸음"에 걸렸다 (11-26 앱 확인). 측정에서도 필기 중 감김으로 보인 프레임의 90%가 10° 이상이었고, 실제로 눈을 감은 프레임은 고개를 든 채 0° 근처였다. 숙인 채 조는 것은 위 표(얼굴을 놓친 구간)로 넘긴다.
- 숫자는 `config/aggregation.py`의 `HEAD_UPRIGHT_PITCH` ~ `SAT_DOWN_LOOKBACK_SEC`. 한 명 측정값이라 임시다.
- 사람 영역 모델이 없으면 3~5는 건너뛰고 예전처럼 자리비움.
- 이 측정을 새 규칙에 다시 넣은 결과 (초): 필기 101 → 자리에 있음 101 / 졸다 떨굼 → 졸음 20 (예전 0) / 숙인 채 졸기 → 판정불가 30 / 숙인 채 나감 → 자리비움 39 / 평소 자세에서 나감 → 자리비움 32 (예전과 같음).

## 확인 (1분 반)

```powershell
python -m cv_module.check_head_down               # 다른 웹캠이면 --camera 1
```

화면 안내대로 움직인다. 단계가 바뀔 때마다 삐 소리가 나서 고개를 숙이거나 눈을 감고 있어도 넘어갈 때를 안다.

| 단계 | 시간 | 이렇게 | 나와야 할 것 |
| --- | --- | --- | --- |
| 캘리브레이션 | 5초 | 평소처럼 화면 보기 | |
| 1 화면 보기 | 10초 | 평소처럼 | 자리에 있음 |
| 2 필기 | 25초 | 고개 숙여 실제로 노트에 쓰기 | 자리에 있음 |
| 3 화면 보기 | 8초 | | 자리에 있음 |
| 4 졸다 고개 떨굼 | 12초 | 눈 감고 3초 버티다 고개를 툭 떨구고 그대로 | 졸음 |
| 5 화면 보기 | 8초 | | 자리에 있음 |
| 6 일어나 나감 | 15초 | 일어나서 카메라 밖으로 | 자리비움 |
| 7 돌아와 화면 | 10초 | 돌아와 앉아 화면 보기 | 자리에 있음 |

끝나면 터미널에 `| 단계 | 초 | 기대 | 지금 규칙 | 새 규칙 | 결과 |` 표가 나온다. 단계마다 처음 2초는 자세 바꾸는 시간이라 뺀다. `결과`가 모두 `OK`면 된다. `확인 필요`가 있으면 `data/head_pose/check_<시각>.json`(초마다 판정값만, 영상 없음)을 공유한다.

앱에서도 확인할 수 있다: 세션 중 필기한 구간이 리포트에서 자리비움이 아니라 집중(작업 창일 때)으로 나오면 된다. 터미널 로그에서 세션 끝에 `CV slot N | ... | 소급 head_down 7초`처럼 다시 보낸 슬롯이 보인다.
