## 이 문서 쓰는 법

이 문서는 **팀 전체가 같이 보는 큰 그림**이다. 세부 작업(함수 단위, 테스트 케이스 단위)은 각자 개인 문서(`PROGRESS_이름.md`, 로컬 전용)에 적고, 여기에는 모듈·화면 단위의 큰 작업만 적는다.

**언제 고치나**

- 작업을 시작할 때: 내 작업의 상태를 `[~]`로 바꾸고 "지금 하는 일" 표를 고친다.
- PR을 올릴 때: 상태를 `[r]`로, PR 번호를 적는다. **이 문서 수정은 그 작업 PR에 같이 넣는다.**
- merge된 뒤: 다음 PR에서 `[x]`로 바꾸고 작업 로그에 한 줄 추가한다.
- 팀 회의 후: "팀이 정해야 할 것"과 "모듈 간 약속" 표를 회의한 사람이 갱신한다.

**충돌 줄이기**

- **자기 담당 섹션만** 고친다. 다른 사람 섹션에 할 말이 있으면 PR 코멘트나 단톡으로.
- 작업 로그는 **맨 아래에 줄 추가만** 한다 (중간 수정·정렬 금지).
- merge 충돌이 나면 양쪽 줄을 모두 남기는 쪽으로 해결한다.

**상태 표기**

| 표기  | 의미                           |
| ----- | ------------------------------ |
| `[ ]` | 시작 전                        |
| `[~]` | 진행 중 (브랜치 있음)          |
| `[r]` | PR 올림, 리뷰 대기             |
| `[x]` | main에 merge 완료              |
| `[-]` | 취소·보류 (이유를 비고에 적기) |

**작업 ID**: 모듈 기준 접두어 + 번호. 담당이 바뀌어도 ID는 그대로 둔다.

| 접두어   | 범위                             | 담당        |
| -------- | -------------------------------- | ----------- |
| `SET-`   | 레포·스키마·mock 등 공동 세팅    | 전체        |
| `CV-`    | 웹캠 CV 모듈 (`cv_module/`)      | 김시언      |
| `WIN-`   | 활성 창 추적 (`window_tracker/`) | 신명철      |
| `SCORE-` | 집중도 점수·LLM 연동             | 신명철      |
| `GUI-`   | GUI·슬롯 로그·저장               | 김민서      |
| `INT-`   | 실제 모듈 통합                   | 김민서 주도 |
| `VAL-`   | 검증·튜닝                        | 김시언 주도 |
| `FIN-`   | 마무리 (테스트·발표·보고서)      | 전체        |
